# 共享画布 ShareCanvas

基于画布的共享创作涂鸦：在无限画布上 2D 涂鸦、书写文字、绘制形状，切换到 3D 场景摆放/编辑立体草稿，还可以把作品实时分享给好友一起创作。

## 技术栈

- TypeScript + Vite + React 19
- Tailwind CSS v4
- react-three-fiber + three（3D 草稿）
- Node.js + ws（WebSocket 实时协作）
- zustand（状态管理）
- Yjs + y-websocket（CRDT 无冲突协作）
- perfect-freehand（平滑可变宽度手写笔迹，tldraw/Excalidraw 同款）
- 多种笔型：钢笔 / 毛笔 / 马克笔 / 铅笔（不同压感曲线、粗细与透明度）
- OffscreenCanvas 渲染 Worker：图层光栅化移出主线程，平移只做位图合成；不支持的环境自动回退主线程渲染

## 快速开始

```bash
npm install
npm run dev:all   # 同时启动 Vite（5173）与协作服务器（8787）
```

也可以分开跑：`npm run dev` 只启动前端，`npm run server` 只启动协作服务器。

生产模式：

```bash
npm run build
npm start         # 默认 http://localhost:8787
```

端口可用 `.env` 里的 `PORT` 配置。

## 测试

```bash
npm run test:e2e
```

端到端测试会自动构建生产包、在 8791 端口启动服务器，并用本机 Chrome/Edge 真实跑一遍核心交互（画笔/荧光笔/橡皮擦、8 种图形、文字输入与附着、箭头吸附、Ctrl+Z 撤销、双击编辑、工具栏遮挡回归）。找不到浏览器时设置环境变量 `CHROME_PATH` 指定可执行文件路径。

## 功能

- 2D 无限画布：画笔、荧光笔、橡皮擦、文字、矩形/圆角矩形/椭圆/菱形/平行四边形/六边形/线条/箭头（含流程图常用图形）
- 右键或中键拖拽平移，滚轮缩放，双指捏合缩放（触屏）
- 撤销 / 重做 / 清空，自动保存到浏览器本地
- 3D 场景：方块、球体、圆柱、圆锥、圆环、平面；拖拽移动、旋转/缩放微调、改色、复制、删除
- 涂鸦转 3D：选中 2D 涂鸦笔迹后一键生成 3D 管状立体
- 实时协作：基于 CRDT（Yjs）的房间同步，多端同时编辑不会互相覆盖，看到彼此的实时光标
- 离线分享：无服务器时也可生成带完整内容的快照链接，或导出/导入 JSON
- 数位板支持：外接压感笔（Wacom/高漫/绘王等）直接可用，笔迹粗细随压感变化，手掌触摸自动忽略
- 服务端持久化：房间内容按增量更新落盘到 `data/rooms/`（可用 `DATA_DIR` 环境变量改路径），服务器重启后房间自动恢复

## 操作提示

- 空格 + 左键拖拽 = 平移
- 右键 / 中键拖拽 = 平移
- 选择工具下空白处左键拖拽 = 平移
- 滚轮 = 缩放
- Ctrl+Z / ⌘+Z = 撤销；Ctrl+Shift+Z、⌘+Shift+Z 或 Ctrl+Y = 重做
- Ctrl+C / ⌘+C、Ctrl+V / ⌘+V = 选择模式下复制粘贴图形/笔迹/文字
- Ctrl+D / ⌘+D = 删除选中的图形/笔迹/文字
- Delete / Backspace = 删除选中内容
- 3D 视角：左键拖拽旋转视角，滚轮缩放，右键平移
